**Blinkshield Admin**

An admin dashboard for managing and monitoring the Blinkshield platform. This project handles the administrative side of the system, giving admins full control over data, users, and platform operations.

**Overview**

Blinkshield Admin is a web-based admin panel built to streamline backend management. It provides a clean, functional interface for administrators to oversee day-to-day operations.

**Features**

- Admin authentication and secure login
- Dashboard with key platform data
- Add Wardrobe
- Add Achievements for users
- Create, Update, Delete Records
- Responsive and user-friendly interface

**Tech Stack**
- Frontend:CSS & JavaScript
- Backend: C#, PHP
- Database: MySql

Other: Canva for designing
